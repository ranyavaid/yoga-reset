# Yoga Reset — Project Notes

## Current Product Direction

A calm mudra-based micro-reset app for work breaks and mindful breathing.

Users:

- hold mudras in front of the camera

- follow breathing guidance

- complete short 45-second reset sessions (5s settle-in copy, then a 40-second guided countdown)

---

## Tech Stack

- React

- Vite

- TypeScript

- MediaPipe Hands

---

## Current Features

- Webcam tracking

- Gyan Mudra support

- Vayu Mudra support

- Mudra library structure

- 45-second guided reset flow
